# My personal site!

My portfolio kinda thing. For myself, by myself, to myself.

[Live website](https://hustlenix.github.io/-personal-site-/) · [Source](https://github.com/Hustlenix/-personal-site-)

## Description

It is basically all about me. I'm Lalith, and this is where you can check out the things I build, a bit about me, and how to reach me. I made it so my projects and contact links have one place to live.

The design mixes Spider-Man and Iron Man with big text, thick borders, and a light mode plus a dark JARVIS mode. The project section links to my games and other websites. This site itself uses plain HTML, CSS, and JavaScript.

## Getting Started

### Dependencies

To visit it, you need a device with a browser and internet. That's it.

If you want to clone it, you also need Git. There are no packages to install or build commands to run.

### Installing

You don't need to download anything to use the [live website](https://hustlenix.github.io/-personal-site-/).

If you wanna use it as a starting point for your own site:

```sh
git clone https://github.com/Hustlenix/-personal-site-.git
cd ./-personal-site-
```

Replace my details and project links in `site/index.html` with yours. The styles are in `site/styles.css`, and the theme toggle and animations are in `site/script.js`.

### Executing program

1. Open the downloaded repository folder.
2. Open the `site` folder.
3. Open `index.html` in your browser.

That's the local version. Edit the files and refresh the page to see your changes.

To put your own copy online, push it to GitHub and select **GitHub Actions** under **Settings → Pages**. The included workflow publishes the `site` folder when you push to `main`. Update the website URLs in `site/index.html`, `site/404.html`, `site/robots.txt`, and `site/sitemap.xml` for your own address too.

## Help

- If the local page looks unstyled, make sure you opened `site/index.html` and kept `styles.css` and `script.js` in the same folder.
- If your edits don't show up, refresh the page. For the online version, check that the deployment finished in the repository's Actions tab.
- If the fonts don't load, check your internet connection. The fonts come from Google Fonts.

For anything else, check the Signal section on my [website](https://hustlenix.github.io/-personal-site-/), or [open an issue](https://github.com/Hustlenix/-personal-site-/issues).
